# Estudisc — Marca e assets

Versão atual: [VERSION](VERSION). Tokens: `design-tokens.json`.

O nome atual é **Estudisc**. O símbolo geométrico já usado pelo aplicativo permanece provisoriamente, até existir um novo desenho aprovado. A troca de nome não redesenha a interface.

| Arquivo | Uso |
|---|---|
| `assets/estudisc-mark.svg` | símbolo geométrico atual |
| `assets/estudisc-mark-mono.svg` | versão monocromática |
| `public/branding/estudisc-mark.svg` | asset usado pelo `BrandLockup` |
| `src/app/icon.svg` | ícone vetorial da aplicação |
| `src/app/apple-icon.png` | ícone Apple existente |

`BrandLockup` renderiza **Estudisc** como texto vivo na tipografia do produto. Ícones raster mantêm a geometria existente. Os nomes antigos em `public/branding/` são aliases deprecated para clientes com assets em cache; código novo usa `estudisc-`. As explorações anteriores estão no histórico e não definem a marca atual.

Preservar proporção, contraste, área de respiro, foco e acessibilidade. O símbolo decorativo usa alt vazio quando acompanha o nome textual. A identidade provisória não exige imagem gerada.
