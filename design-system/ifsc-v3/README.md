# Estudisc — delta IFSC histórico integrado

Versão atual: `../VERSION`. Este diretório conserva o nome da origem histórica e não define uma segunda versão atual.

Status: **Delta integrado**

This delta is already integrated into the current normative Design System. Do not create a competing production token source.

## Direction

**Functional Neo-Brutalism + Mobile-First Learning**

Preserve:

- accessibility precedence;
- token generation;
- warm paper / dark ink;
- Archivo + JetBrains Mono roles;
- explicit borders;
- hard structural shadows;
- mechanical press motion;
- no color-only state;
- no continuous decorative animation.

Change:

- student layout is mobile-first;
- learning surfaces replace Programming Lab as the default visual reference;
- bottom navigation becomes primary student navigation on mobile;
- educational interactions become first-class components;
- subject accents may be more expressive but remain secondary to semantic state;
- Programming Lab is a width-sensitive desktop progressive enhancement.

## Approved inspiration policy

Foundation/owned primitives first. External references are inspiration/source-code inputs, not a visual patchwork.

Preferred order:

1. existing Estudisc component;
2. shadcn-style accessible primitive/pattern;
3. approved source component adapted into Estudisc tokens;
4. purpose-built component.

Useful reference registries may include Arc/UIArc, Motion Primitives, Planes, Space UI, 21st.dev, Component Gallery, Magic UI, Aceternity, Componentry, Skecher UI and Uiverse. Spline/Unicorn are experimental and not core learning dependencies.
