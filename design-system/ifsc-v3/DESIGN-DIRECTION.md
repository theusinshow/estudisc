# Design Direction v3

## Thesis

The interface should feel like a tactile study instrument: clear structure, strong typography, explicit surfaces and physical press feedback.

It must not feel like a noisy portfolio demo or a childish game.

## Visual language

- warm light background;
- near-black primary ink;
- 2px structural borders by default;
- solid offset shadows;
- bold headings;
- restrained but saturated accents;
- moderate radius where mobile ergonomics benefit;
- one dominant action per decision context.

## Subject accents

Subject color is an accent, not a semantic state:

- Mathematics: yellow-family accent;
- Portuguese: purple-family accent;
- Science: green-family accent;
- Geography/History: blue/orange-family accent.

Success/error/warning/info continue to use semantic tokens plus non-color indicators.

## Anti-patterns

Avoid:

- border around every paragraph;
- random color per card;
- decorative 3D in study flow;
- glassmorphism;
- diffuse SaaS shadows;
- animation for its own sake;
- mascot/emoji as primary language;
- oversized visual effects that reduce mobile reading space.
