# Science V2 media contract

Worker owns `.local/science-integration/media/` only. Existing ADR0032 `figure` renderer and safe 200000-byte embedded SVG/PNG/JPEG/WebP schema are authoritative. No new renderer/schema, public files, external embeds or speculative scientific geometry.

Write `.local/science-integration/media/assets.json` as `{ "assets": [...] }`. Each entry: `requestId` (exact `COMP-CIE-XX-001`), repository-relative `path`, lowercase raw-file `sha256`, `mime` (`svg+xml|png|jpeg|webp`), `alt` (>=12 chars), `caption`, `credit`, `longDescription`, positive integer `width`,`height`, `status: LOCAL_DETERMINISTIC_DRAFT`. `tools/science-import/contracts.ts` validates this manifest. Only verified package facts may enter diagrams; pending/factually underspecified requests remain pending, never replaced by generative art. No generated-image asset receives this deterministic status.

CLI `--stage media --media .local/science-integration/media/assets.json` embeds local draft figures into matching source request blocks without rewriting editorial source, after pilot+5batches. Preserves raw source block and full asset manifest in sidecar; payload.editorial is id/type/canonicalHash, payload.media is requestId/sha256/status. All scientific labels need a complete text equivalent in longDescription. SVG rejects scripts/events/foreignObject/external references and renders via img. Figures are drafts and require visual/factual human review. Added/changed media requires a new cumulative snapshot version; reusing pack ID/version with changed bytes must conflict.
