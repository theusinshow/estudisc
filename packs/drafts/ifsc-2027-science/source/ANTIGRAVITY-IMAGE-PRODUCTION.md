## Regra central
Se o conteúdo exigir exatidão estrutural, numérica, anatômica, geométrica ou de escala, não use Nano Banana como fonte do diagrama.

## CIE-24
Não gerar pessoas ou representações culturais sintéticas. Para perspectivas indígenas e quilombolas, usar mídia documental/educacional licenciada de instituições e comunidades/fontes apropriadas.

## Fluxo
`image request → Antigravity → generated asset → visual review → factual review → approved`

O agente gerador nunca pode promover a própria imagem para `APPROVED`.
