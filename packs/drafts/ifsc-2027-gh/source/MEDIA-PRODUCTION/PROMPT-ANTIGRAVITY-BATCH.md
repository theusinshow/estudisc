# Prompt — VECTA GH Image Producer

Leia `ANTIGRAVITY-QUEUE.json` e `VISUAL-SYSTEM.md`.
Gere somente os requests presentes na fila. Use Nano Banana 2 pela capacidade nativa do Antigravity.

REGRAS ABSOLUTAS:
- não criar ou simular fotografia/documento histórico;
- não inventar mapas, fronteiras, datas, bandeiras, uniformes ou personagens reais;
- não incluir texto embutido;
- ilustrações devem ser claramente conceituais/editoriais;
- salve com o `outputFilename` solicitado;
- gere metadata com prompt, model, requestId e status `FACTUAL_REVIEW_PENDING`;
- não marque asset como aprovado.

Se um request exigir precisão cartográfica/histórica que não possa ser garantida, não gere e reporte `DETERMINISTIC_OR_AUTHENTIC_SOURCE_REQUIRED`.
