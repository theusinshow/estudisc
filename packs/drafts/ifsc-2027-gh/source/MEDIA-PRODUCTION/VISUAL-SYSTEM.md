# VECTA GH — Visual System

- Mobile-first, editorial, claro e sem decoração gratuita.
- Documento/fotografia/gravura histórica: somente fonte autêntica com proveniência.
- Antigravity: apenas ilustração conceitual explicitamente não documental.
- Mapas, gráficos, linhas do tempo, fronteiras, escalas e dados: componentes determinísticos ou fontes oficiais.
- Nunca criar “foto histórica” sintética para ensinar como evidência.
- Diferenciar visualmente `DOCUMENTO HISTÓRICO`, `MAPA/DADO OFICIAL`, `ILUSTRAÇÃO VECTA` e `RECONSTRUÇÃO ESQUEMÁTICA`.
