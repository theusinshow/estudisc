# ADR 0047 — Source-bound enrichment review previews

Status: Accepted for local review preparation (2026-10-07).

## Context

Phase 8 generated 132 UNREVIEWED proposals, with 113 missing explicit objectives. Phase 9 needs actual blueprint and independent pilot review before batches. Continuing local implementation must produce a concrete reviewable result without inferring approval or modifying published versions.

## Decision

Extend existing Studio CLI with an isolated, generic, source/hash-bound preview recipe for the existing percentage explorer. Pin exact source objective/Concept/quote/placement and initial calculation; add one exploratory block in a next-version draft review candidate while preserving original blocks/activities/shared Question identities and hashes. Retain source caveats. Do not add a review/approval state machine or import/export path.

All previews and requests remain REVIEW_REQUIRED, including high-confidence blueprints. A pending blueprint can be illustrated for review, never applied as reviewed enrichment. Existing Studio independent role ownership, seven-dimension reports and human export/publication boundaries remain authoritative. No simulation of independent approval occurs for actual content. Test-only fixtures do not constitute editorial evidence.

## Consequences

New recipe/preview sidecars are confined to ignored local authoring storage. Complete source/blueprint/Question/policy/assets hashes prevent stale reuse and corrupted outputs regenerate. No Pack schema, runtime registry, evidence engine, auth boundary or production migration changes. Reviewed blueprint consumption, actual draft promotion and batch enrichment remain later work after actual review.
