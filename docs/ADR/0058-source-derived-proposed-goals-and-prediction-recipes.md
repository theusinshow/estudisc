# ADR 0058 — explicit source-derived proposed goals for exploration

Date: 2026-10-08. Status: Accepted under continuous implementation/direct-release authorization; current model/effort retained, no extra agents or independent reviewer claimed.

The original corpus has 113 lessons without declared objectives and worked blocks with empty Concept links. Do not replace these original absences or fabricate original mapping. For a bounded exception whose authored scenario/explanation clearly supports a learning purpose, introduce Studio authoring recipe v2 with an explicitly SOURCE_DERIVED_PROPOSAL goal and actual source block/hash/quote plus existing lesson Concept IDs. New links are authorial derivations, not historical facts. Keep original lesson objectives/blocks/Activities/Concepts/Question versions/hashes unchanged; append only new draft-version blocks through the existing targeted importer.

Reuse prediction's existing schema/renderer/response/feedback/touch/keyboard/typed resume. The new block visibly names its proposed exploratory goal, presents a source-supported prediction, and reuses original observation/explanation. It records no official Attempt or ConceptEvidence and does not claim mastery. Its flag-off path remains static text. No new Question, media, assessment evaluator, Pack envelope or publication engine.

The original heuristic blueprint remains UNREVIEWED and may not recommend prediction. Recipe v2 records an explicit source-bound exception selection/reason; do not mutate the historical blueprint's recommendation, confidence or review state to pretend approval. Bind the exact identity/wrapper source hash and raw lesson/block hashes; validate source quote inclusion and proposed Concept membership. Copy no independent approval from anchor metadata. Existing actual Admin Direct authorization follows engineering QA; community feedback follows launch.

Retain exact recipe v1 parsing/hashes/numeric output, and version the authoring recipe rather than silently broadening v1. Recipe v2 permits only non-assessed prediction in this increment; no arbitrary model/code/media/grade fields. Current accepted examples: CIE-03 direction of heat transfer toward thermal equilibrium; POR-02 distinguishing library text theme/main idea/explicit information without extending a Saturday-specific observation to total attendance. GH-04's generic source remains an exception.

Tests cover old recipe compatibility, source/quote/hash/identity/Concept/goal-origin guards, immutable fields/Questions, actual desktop/mobile predict-observe-explain and owner/version resume, flag-off readable fallback and zero official evidence. Rollback keeps original published versions and disables new exploratory presentation; no old content/history is transformed.
