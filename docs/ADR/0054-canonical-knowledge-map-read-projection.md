# ADR 0054 — canonical knowledge-map read projection

Date: 2026-10-08. Status: Accepted under continuous evolution authorization.

Extend existing Concept/catalog/curriculum readers. Published availability comes from actual lesson versions/releases; owned mastery uses calculateVersionedMastery and review badges use actual due schedules. Unseen denotes no mastery evidence, not proof that a learner never read a lesson. Consolidated groups existing strong/mastered states; exact canonical labels remain visible.

Keep track/source scope, prerequisite direction and required/recommended strength. Do not merge different tracks into a global unlock rule. Required readiness reports the existing planner threshold (level >=2); recommended links do not block. Reading the map never propagates evidence/mastery, grants access, changes priority or writes learner state. Missing/external references remain explicit data limits.

Reuse cycle validation per track. Aggregate display cycles use bounded layout/list fallback and never mutate edges. React Flow is lazy, read-only and optional behind FEATURE_KNOWLEDGE_MAP; disable node/edge edits, retain accessible subject/list navigation and keyboard/touch details. Preserve tokens/CSP/reduced motion. No Pack schema, migration or parallel engine.

Validate SQL/memory publication/owner/state/edge parity and no evidence writes, off avoids heavy canvas, mobile/list fallback and keyboard controls. Full gates precede direct protected release; flag off restores the previous hierarchy.
