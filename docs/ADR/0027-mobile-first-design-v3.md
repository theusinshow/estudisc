# ADR 0027 — Adopt Design System v3 as mobile-first and learning-first

Status: Accepted

## Context

The existing Design System 2.2 is Technical Brutalism and was desktop-first for programming. The IFSC student is expected to use mobile more often.

## Decision

Evolve rather than replace the visual system.

Design System v3 direction:

- mobile-first student flows;
- learning-first hierarchy;
- functional neo-brutalism;
- preserve accessibility precedence, token pipeline, warm paper/ink, explicit borders and hard shadows;
- Programming Lab remains a desktop-enhanced exception.

## Consequences

Responsive specs and student navigation change. Existing code should migrate through tokens/components rather than one-off restyling.

## Rejected alternatives

- discard the current design system;
- decorative maximalist neo-brutalism;
- mobile as a later adaptation.
