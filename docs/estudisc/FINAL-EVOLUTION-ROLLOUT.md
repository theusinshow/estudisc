The shape reader verifies nullability through pg_attribute.attnotnull and excludes redundant relation NOT NULL catalog rows, which PostgreSQL 18 adds while 17 stores them only on attributes. This preserves the same required nullability checks across database versions, including a nullable-column drift test. Primary documentation: [PG18 constraints](https://www.postgresql.org/docs/18/catalog-pg-constraint.html), [PG17 attributes](https://www.postgresql.org/docs/17/catalog-pg-attribute.html).
