# 01 — IFSC Exam Analysis

Status: **Accepted**
Sources: Edital 05/DEING/2027/1 and Integrated exams 2025.1–2026.2.

## Normative format

Official 2027/1 exam:

- date: 29/11/2026;
- start: 14:00;
- duration: 4 hours;
- 28 multiple-choice questions;
- alternatives A–E;
- 7 Língua Portuguesa;
- 7 Matemática;
- 7 Geografia e História;
- 7 Ciências.

The Anexo V program is authoritative for curriculum coverage.

## Historical evidence

Use only the Technical Integrated (`INT`) exams as primary historical references:

- 2025.1;
- 2025.2;
- 2026.1;
- 2026.2.

Observed design characteristics to classify rather than assume:

- contextual source texts;
- charts/tables/maps/images where appropriate;
- everyday, scientific, historical and Santa Catarina contexts;
- application and interpretation mixed with direct knowledge;
- five plausible alternatives;
- questions sometimes combine multiple concepts.

Do not convert four editions into pseudo-precise forecasts such as “topic X has 72% chance to appear.”

## Blueprint metadata

Every imported official question should classify:

- subject;
- primary concept;
- secondary concepts;
- difficulty;
- cognitive operations;
- stimulus type;
- contextualization;
- official answer;
- status;
- provenance;
- exam/year/semester/question number.

Suggested cognitive operations:

`RECALL, IDENTIFY, INTERPRET, CALCULATE, COMPARE, INFER, APPLY, ANALYZE, EVALUATE`

Suggested stimulus types:

`NONE, TEXT, IMAGE, MAP, GRAPH, TABLE, DIAGRAM, MIXED`

## Historical exam allocation

- 2025.1 → training / examples / empirical analysis;
- 2025.2 → training / examples / mini assessments;
- 2026.1 → protected intermediate benchmark;
- 2026.2 → protected final benchmark.

A reserved exam is not available to normal practice selection before release.

## Annulled questions

2025.1 Integrated Question 15 is annulled in the definitive answer key.

An annulled question:

- remains in historical records;
- can be inspected by Admin;
- cannot score an assessment;
- cannot emit mastery evidence;
- is excluded from valid benchmark metrics.

## Source hierarchy

1. current edital → curriculum and current format;
2. definitive answer keys → official status/answer for their edition;
3. historical Integrated exams → wording, style and empirical blueprint;
4. generated/derived questions → practice only, clearly labeled by provenance.
