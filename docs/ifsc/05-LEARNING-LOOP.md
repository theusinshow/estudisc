# 05 — Learning Loop

Status: **Accepted**
Source of truth for: StudySession behavior.

## Lesson vs StudySession

A Lesson is published content.

A StudySession is the frozen set of actions the learner performs now and can include review, lesson blocks, practice and an exit ticket.

## Typical session

`Start → Retrieval → Adaptive recap → New content → Worked example → Guided practice → Exploration → Independent practice → Interleaved practice → IFSC transfer → Exit ticket → Result → Evidence/Review updates`

Not every session needs every stage.

## Time budgets

Student may choose:

- 15 min;
- 30 min;
- complete session.

Shortening a session is not arbitrary truncation. The Session Builder selects a coherent subset, prioritizing urgent reviews and high-value learning items.

## Session states

- `PLANNED`
- `ACTIVE`
- `COMPLETED`
- `ABANDONED`

When a session becomes ACTIVE, its item composition is frozen.

## Missed days

Missed sessions do not stack as punitive debt. Planner recomputes future work. Due review urgency remains real but new-content backlog is not displayed as a growing failure count.

## Resume

Persist sufficient progress to continue a StudySession after interruption. Already-generated evidence remains valid.

## Result screen

Show, in this order:

- study time;
- Concepts strengthened;
- Concepts needing reinforcement;
- scheduled reviews;
- next suggested action;
- optional secondary gamification.

Do not show unsupported admission probability.
