## Required flow

1. prior-knowledge prediction;
2. interactive atom/model;
3. particle classification;
4. atomic-number/mass concept;
5. worked example;
6. guided atom;
7. ion prediction;
8. independent practice;
9. transfer;
10. exit ticket.

## Interactive model

Learner changes:

- protons;
- neutrons;
- electrons.

The model shows:

- atomic number;
- mass number;
- net charge.

Before revealing a changed charge, ask for prediction where pedagogically useful.

## Misconception handling

If learner calculates atomic number as protons + neutrons, feedback distinguishes atomic number from mass number and classifies a conceptual error.

## Accessibility

Diagram must have a structured text/table alternative. All controls must be keyboard/touch operable.

## Regression purpose

Validates diagram/model blocks, prediction, derived values, classification and non-text-only learning.
