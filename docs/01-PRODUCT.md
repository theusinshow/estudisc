# 01 — Product Definition

## Approved IFSC product extension

Today → StudySession answers what to study now. Add EXAM mode: no hints, tutor or correctness feedback until finalization. BUILD remains for programming. Coverage, evidence, retention and assessments describe progress; no admission probability. See [IFSC product](ifsc/00-IFSC-PRODUCT.md).

## Users

The original V1 served one owner. ADR 0026 approves private allowlisted ADMIN and STUDENT profiles mapped to distinct owners. Students own learning state; Admin manages curriculum, sources, QA and publication. No public signup, organizations, billing or classrooms.

## Core jobs

- Import a structured learning path.
- Continue from the correct point.
- Study concepts through structured blocks.
- Practice through multiple activity types.
- Run and debug code in a focused environment.
- Record immutable attempts.
- Review weak or due concepts.
- Understand recurring errors.
- Connect concepts to real projects.
- Export context for a teacher or AI assistant.
- Back up all learning data.

## Main modes

- **LEARN:** understand new concepts.
- **PRACTICE:** create evidence through activities.
- **REVIEW:** strengthen recall after time has passed.
- **BUILD:** apply knowledge to a real or realistic context.

## Product language

Brand: `Estudisc`
Technical identifier: `estudisc`
Positioning: `Personal Learning Operating System`

User interface is initially Portuguese. Code, database names and technical contracts use English.

## Success indicators

Success is not measured only by time spent. Useful product indicators include completed review sessions, concepts strengthened with delayed evidence, recurring mistakes resolved, successful transfer to new contexts and continued progress without punitive streak mechanics.
