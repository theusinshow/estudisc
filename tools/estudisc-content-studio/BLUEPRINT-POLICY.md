Original human/editorial review references below are historical release policy, superseded by this instruction.

Use the four exact historically audited import artifacts in `blueprint-sources.ts`. Their local draft status remains unchanged; a prior publication audit does not establish current production state or pedagogical/rights/mapping readiness. Pin raw and normalized hashes. Reuse curriculum-only Studio catalog context and teaching asset eligibility; never extract Question stems, choices, answers, private state, image bytes or source originals.

Extract IDs/version/title/subject/Concepts/objectives/block and Activity types/counts, source IDs and a teaching-text word count. The word count scans a bounded whitelist of teaching text keys, not Question/config answers. Do not export block payloads. Missing objectives produce a null learning goal and a human source-review finding; never substitute Concept titles or invent common mistakes.

Deterministic, accent-insensitive title/Concept/objective keywords propose spatial, chronological, numeric, process, classification, interpretation and comparison archetypes; otherwise use explanation. Keywords are signals, not comprehension or new pedagogy. Proposals target existing blocks only. `numeric-explorer` requires an approved compatible model; `map` means the authored image/list, not installed geographic tiles. Process uses guided steps/ordering, not an unimplemented animation. Custom simulation/complex diagrams require separate exception review when explicitly requested; the extractor does not invent them.

Heuristic confidence: base 0.45, explicit objectives +0.25, specific keyword match +0.20; missing objectives or invalid prerequisites cap at 0.60. No matching rule, missing objectives, unresolved prerequisite reference/cycle and score below 0.70 are explicit exceptions. All results are UNREVIEWED, including high confidence. Confidence is neither evidence weighting nor factual/independent certification. Review human source gaps first; send only precise unresolved pedagogical decisions to Terra, never all full lessons. Sol High is reserved for an actual exceptional risk.

Each sidecar binds identity, sourceHash, corpusHash, dependencyHash (catalog/mappings/prerequisites), policyHash (implementation/schema/policy), assetHash (current inventory/rights policy), inputHash, version and generatedAt. Whole-corpus/asset invalidation is deliberately conservative. Filename binds identity and complete inputs, retaining previous proposal generations. Skip only if recomputed deterministic proposal equals the validated cache with its original timestamp; corruption or invented review state regenerates. Index/report are deterministic and include artifact hashes. No review approval is cached or carried forward.

Artifacts remain local in an ignored Studio workspace `lesson-blueprints/`; Studio path/symlink checks and atomic JSON writes apply. No network, import, publication, source mutation, learner write, database migration or runtime decision is made. Admin Blueprint Viewer/content enrichment are later consumers and require actual review/approval.
