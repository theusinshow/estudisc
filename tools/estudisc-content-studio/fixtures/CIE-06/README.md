# DEMO / NOT PRODUCTION CONTENT

This minimal, version-controlled fixture uses the real CIE.ATOM.Z Concept ID and runtime Lesson/Question schemas. It deliberately omits complete teaching, real scientific research and official curriculum coverage. Its source verification and image embedding rights concern this synthetic local test only.

Run `pnpm estudisc-content demo --workspace .local/content-studio-demo` in a new workspace. The tool claims each stage, writes these artifacts, creates a simulated HIGH QA finding, revises the worked-example title, archives the finding and reaches the human gate. Add `--simulate-approval` to exercise draft-only promotion with an explicitly simulated approval. No independent approval, database import or publication is performed. Existing demo jobs are never overwritten.

The QA reports are generated from actual stage input hashes, rather than copying stale reports from this fixture. The approved output contains `pack.json`, `editorial.json` and `manifest.json`; all runtime statuses are `draft`.
