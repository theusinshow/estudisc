# Compact pedagogy rules

Teach the requested Concepts and prerequisites with an appropriate sequence: retrieval, hook/context, short explanation, visual if useful, worked example, guided practice, interaction if useful, independent practice, transfer/IFSC-style item and exit ticket. Choose rather than mechanically force every phase.

Alternate short explanation → learner action → feedback → next explanation. Retrieve before presenting a summary. Practice should differ from worked examples and gradually remove scaffolding. Interleave related Concepts when it helps transfer. Do not replace instruction with ten paragraphs followed by a quiz.

Hints progress from conceptual direction to first step to partial solution; full resolution is separate. Use only actual runtime hint/config behavior. Distractors target misconceptions, not random numbers. Questions vary difficulty and cognition intentionally and map to Concepts. Check all answers and units.

Use visuals to explain spatial/process/quantitative relationships; omit decoration. External media/books remain optional. Portuguese student-facing copy, readable on mobile, meaningful alternatives and registered touch/keyboard interactions. Concept mastery derives from deterministic evidence, never lesson completion or AI judgment.
