# Compact media context

The canonical policy is [MEDIA-POLICY.md](../MEDIA-POLICY.md). Read it before selecting/embedding media.

Research proposes, Author selects, Reviewer verifies. `APPROVED_EMBED` alone permits embedding a produced safe figure with rights evidence and attribution. `LINK_ONLY` permits a supplemental link. `UNKNOWN`, `REQUIRES_REVIEW` and `REJECTED` do not permit embedding. Keep unselected candidates for future research without pretending clearance.

Generated media records `sourceType: GENERATED` and its prompt/specification. A generated-image request is not an existing asset. Production figure requires safe SVG/PNG/WebP/JPEG base64 data URI, ≤200,000 bytes, useful alt text/caption and valid dimensions. No external figure URL or SVG scripts/external references.

Videos/books are optional editorial recommendations; no dedicated video/book block exists. Text can display a URL, but cannot create clickable links or parse Markdown. Request a safe resource-links component when needed. Record verified metadata/segments and recommendations without invented dates/pages. Do not copy commercial textbook pages/diagrams or protected official assets. Lesson content must remain useful if all supplements disappear.
