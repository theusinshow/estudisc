# Compact QA context

The canonical rubric is [QA-RUBRIC.md](../QA-RUBRIC.md). Review dimensions: STRUCTURAL, FACTUAL, PEDAGOGICAL, IFSC_ALIGNMENT, MEDIA, COPYRIGHT, ACCESSIBILITY. Severity: INFO, LOW, MEDIUM, HIGH, CRITICAL.

HIGH/CRITICAL block approval. Wrong key, multiple correct interpretations, fake evidence, false official identity, unauthorized media or broken/unsafe interaction are CRITICAL examples. Deterministic structural validity is necessary but cannot prove pedagogy or facts.

Review independently, identify targets/evidence/fixes, do not rewrite Author artifacts. Copy active review claim input hashes exactly; reviewerId equals the actual owner and differs from Author. Decisions: APPROVED, NEEDS_REVISION, REJECTED. Approved agent review stops for human local export approval; runtime publication still requires independent human QA. DEMO simulation never counts as real approval.
